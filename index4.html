HR Portal Modernization – UX Case Study

Accenture | India | Oct 2019 – Apr 2022

Project Overview

Designed and modernized a self-service HR portal for a Fortune 500 enterprise client using Figma and Adobe XD, reducing support queries by 40% and enhancing usability for over 20,000 users.

Key Contributions

  • Collaborated with developers to build a mobile-first claims management system using Vue.js, HTML5 & SCSS.
  • Conducted usability tests, built wireframes and refined user flows from A/B test insights.
  • Built design systems compatible with Angular and React, reducing duplication by 60%.
  • Worked in Agile teams using Jira and Confluence to document design standards.
  • Created prototypes and incorporated usability feedback into mockups and final UIs.
  • Ensured WCAG 2.1 compliance across mobile and desktop platforms.
  • Collaborated with developers, PMs, and QA to deliver scalable and accessible UI solutions.
  • Maintained design consistency using component libraries and Atomic Design principles.
